# Security policy

SilverSetup is an unreleased application scaffold. There are no supported releases or published security-fix commitments yet.

Do not disclose a suspected vulnerability in a public issue. Until a verified private reporting channel is published, contact the project owner through an existing private channel. Before public distribution, the owner must enable private vulnerability reporting and update this policy with its working link.

Include the affected revision, platform, reproduction steps, and potential impact. Never include credentials, tokens, private keys, personal paths, or sensitive logs. Do not expect a response or remediation deadline until a supported release and reporting process are announced.
